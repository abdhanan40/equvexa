# Equvexa Riding 🏇

Equvexa Riding is a modern B2B horse riding equipment website designed to showcase premium equestrian products for international buyers, retailers, and distributors.

## About the Project

The platform focuses on presenting horse riding accessories in a clean, professional, and business-oriented way. It is designed for product discovery, brand presentation, and direct customer inquiries.

## Products

- Riding Gloves
- Stirrups
- Riding Chaps
- Horse Salt
- Horse Riding Caps
- Riding Saddles
- Horse Bits

## Key Features

- Modern and responsive user interface
- Product-focused browsing experience
- Dedicated product pages
- Multiple product images
- Direct WhatsApp contact
- Instagram and Facebook integration
- Mobile-friendly design
- B2B-focused presentation
- Clean and premium visual style

## Tech Stack

- Next.js
- React
- TypeScript
- CSS
- Responsive Web Design

## Project Purpose

The main purpose of Equvexa Riding is to build a professional online presence for a horse riding equipment export business and make it easier for potential buyers to explore products and contact the business directly.

## Project Status

The frontend website is developed and is being continuously improved with better product presentation, UI/UX enhancements, and business-focused features.
